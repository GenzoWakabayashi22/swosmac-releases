# SWOS 2020 Mac Edition

Free download of SWOS 2020 for macOS (Apple Silicon and Intel, macOS 11+), signed and notarized.

Download page: https://swosmac.nathco.app

The launcher is available in English, Italian, French, Spanish and German.

Based on the work of the sensiblesoccer.de team (SWOS 2020) and Sensible Software. Unofficial, not affiliated. Mac conversion by Paolo Giulio Gazzano.
