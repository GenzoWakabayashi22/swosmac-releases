# SWOS Mac

Free, unofficial launcher for macOS (Apple Silicon and Intel, macOS 11+), signed and notarized. It contains SWOS 2020, OpenSWOS and the SWOS 96/97 Mod. Formerly "SWOS 2020 Mac Edition".

Download page: https://swosmac.nathco.app

The launcher is available in English, Italian, French, Spanish and German.

Based on the work of the sensiblesoccer.de team (SWOS 2020), Ben Baker and the OpenSWOS contributors (OpenSWOS, GPL-3.0-or-later, https://openswos.net), Davide Lorigliola (SWOS 96/97 Mod, https://github.com/aminta/swos-9697-mod, included with his permission) and Sensible Software. Unofficial, not affiliated. Mac launcher by Paolo Giulio Gazzano.
